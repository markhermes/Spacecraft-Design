# Spacecraft Design

Models and scripts for spacecraft dynamics simulation, state estimation, and
control. A sandbox for prototyping the kinds of GNC building blocks used in
flight software.

## What's here
- `spacecraft_dynamics_sim/` — 6-DOF (or N-DOF) dynamics simulation
- `2dof_simple.py` — minimal 2-DOF dynamics example
